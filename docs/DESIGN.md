# Fune6900's Gallery — デザイン仕様書（Ver2）

ゼンレスゾーンゼロ（ZZZ）を踏襲したテーマの設計仕様。
用途は **ポートフォリオ / 作品アーカイブ**。

この仕様は **2つのレイヤー**でできている。混ぜて考えると破綻するので分けて扱う。

| レイヤー     | 出どころ                                                       | 担うもの                                              |
| ------------ | -------------------------------------------------------------- | ----------------------------------------------------- |
| **構造**     | [公式サイト](https://zenless.hoyoverse.com/ja-jp/main)の実測値 | 地の色・角丸・書体・レイアウト・UIクロム              |
| **モチーフ** | ゲーム世界の意匠                                               | ブラウン管・VHS・グラフィティ・ネオン・オーディオ機器 |

> **Ver1（暗色 + 面取り + オレンジ）は破棄した。** ゲーム内UIから解釈して作ったもので、
> 公式サイトの実測値とは逆方向だった。比較用のモックは `htdocs/mockup.html` に残してある。
> 現行の設計は `htdocs/mockup2.html`（Ver2 のモック）と対応する。

## 1. 公式サイトの実測値

推測ではなく DOM の computed style を読んで採用した値。

```
背景  #EFEFEF（body）/ #FFFFFF（カード）/ #000000・#111111・#222122（UIクロム）
文字  #000000（主・出現816回）/ #222122 / #787878（副）
強調  #D8FA00（ライム）→ ホバー #C6E800
角丸  75px（ピル）/ 33.75px / 24px / 20px / 8.75px / 0 56.25px 0 0（非対称）
書体  "ja rog" = RoGSanSrfStdN-Bd（ロダン Bold）/ "en impact" = Impact
動き  0.1〜0.2s の ease-out / linear のみ。scroll-snap 不使用
```

**構造の言語**

1. 黒いリボン（細い斜めハッチ）が斜めに画面を横切る
2. 非対称な大きな角丸（1〜2箇所の角だけを大きく丸める）
3. セクション見出しの3段構え — 和文 / 欧文 / 巨大な連番
4. 巨大ゴースト文字（Impact の極大文字を背景に薄く）
5. フィルムのパーフォレーション（角丸の四角い穴が並ぶ黒帯）
6. ライムのハイライト帯を見出しブロックの背景に
7. ボタン・ナビ・セレクタはすべてピル形状

### 書体（商用フォントの代替）

| 用途                   | 書体                                   | 代替元           |
| ---------------------- | -------------------------------------- | ---------------- |
| 巨大数字・ロゴ         | **Anton**                              | Impact           |
| 和文全般・本文         | **Zen Kaku Gothic New**（500/700/900） | ロダン Bold      |
| 欧文サブ・ネオンサイン | **Saira Stencil One**                  | ステンシル       |
| 電光掲示板・機材ラベル | **Silkscreen**                         | ドットマトリクス |

Google Fonts の CDN で読み込む（日本語は unicode-range で分割配信されるため自前ホストより軽い）。

### mixin

`halftone()` `hatch()` `grain()` `stencil()` `dot-label()` `solid()` を `_tokens.scss` に置いている。
`solid()` は「押した感触」— 下辺に硬い影を置き、押下でその分だけ沈める（**90ms**）。

## 4. アニメーション

**すべて `prefers-reduced-motion` で停止する。イントロはそもそも表示しない。**

| 場面             | 動き                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| 読み込み         | 砂嵐 + 垂直同期のずれ + 走査線 → チャンネルを送る → `ON AIR` → ブラウン管が閉じるように畳む（計1.3秒） |
| ページ送り       | クリックで画面が横線に収縮して中央の点へ消える（380ms）→ 遷移                                          |
| カード出現       | opacity を段階遅延でフェード（遅延は8枚ぶんで頭打ち）                                                  |
| チャンネル番号   | スロットのように回り、左の桁から順に確定（420ms）                                                      |
| カードのホバー   | ライムのリング + 走査線が走る + 色収差（90ms）                                                         |
| ランダムグリッチ | 2.6〜6.4秒のあいだで、画面内の1枚を260msグリッチ                                                       |
| レベルメーター   | 常時不規則に振れ、スクロール速度（`--vu`）で伸び、しきい値超で全バーがライムに                         |
| 数字・バー       | スクロールで 0 から数え上がり、バーが伸びる                                                            |
| ゴースト文字     | カーソルに慣性つきで追従                                                                               |
| 大きいカード     | ゆっくり上下に浮く                                                                                     |
| フィルム帯       | 穴が流れる                                                                                             |
| つまみ           | ホバーで回る                                                                                           |

## 5. 画面ごとの構成

### トップ（front-page.php）

ヒーロー（ゴースト文字 / 飛沫 / 黒リボン+ネオン+ペンキ垂れ / スケボー / 3DキューブTV）
→ 電光掲示板 → フィルム帯 → スタッツ帯 → コントロールバー → **全幅ギャラリー** → デッキ型ページ送り

### ギャラリーのグリッド

**セルの高さは画像の比に合わせる。** 固定比のセルに全部入れると、縦長の作品は
上下を削られる。顔はたいていそこにあるので、それが一番痛い。

- 行の刻みを**列幅の 1/6** まで細かくし、各カードの行数を画像の比から計算して
  `grid-row: span N` で渡す（`fune_gallery_tv_geometry()`）
  - 行の高さ = `N*U + (N-1)*G` なので、必要な高さ H に対して `N = (H + G) / (U + G)`
  - 列幅は画面幅で変わるが式は比で効くので、代表値（列 280px / 余白 14px）で
    計算してもどのブレークポイントでも数％の誤差に収まる
  - 実測: 上下の削れは**平均 6% / 最大 12%**（固定 4:3 だったときは最大 36%）
- 行の高さ自体は JS が**実測幅**から `--cell` に入れる
  （`100vw` だとスクロールバーぶんだけ横にはみ出す）
- 列数: 2200px〜 7 / 1700px〜 6 / 既定 5 / 1399px以下 4 / 1099px以下 3 / 767px以下 2
- **7枚に1枚だけ 2列の「見せ札」**にする（位置基準）。ただし極端に縦長のものは
  画面を縦に占領しすぎるので 1列のままにする。傾きは**投稿ID**基準
- `object-position: 50% 30%` — それでも上下が削れる場合に、顔が残るよう上寄せ
- モバイルは `grid-auto-flow: row`（dense だと番号が前後して見える）
- 関連作品も同じ計算を通す。ここで行数を渡し忘れると 1 行ぶんに潰れる

### 作品詳細（single-illustration.php）

ライムの見出し（3段構え）→ 白カードの画像 7 : 黒パネル 5 → ピル型の前後ナビ → 同時期の作品4件

### その他

`search.php`（検索語を見出しに）/ `404.php`（SIGNAL LOST）/ `page.php`（汎用固定ページ）/ `index.php`（汎用アーカイブ）

## 7. アクセシビリティ

- `.fg-reveal` は **`.fg-js` が付いているときだけ**伏せる。素の状態を `opacity:0` にすると
  JS 無効時に内容が永久に見えなくなる。印は `<head>` のインラインスクリプトで付ける
- alt は必ず出す（添付の alt →無ければ作品タイトル）
- 装飾（HUD・メーター・ステッカー・SVG）はすべて `aria-hidden`
- フォーカスリングはライムの 3px。ホバー演出とは別物
- ライトボックスはフォーカストラップ + Esc、閉じたら元の要素にフォーカスを戻す
- スキップリンクあり
- 点滅は1秒3回未満

## 8. 実装メモ（仕様から変えた点・既知の制約）

### transform を触るアニメーションは書かない

カードの transform は `rotate(var(--rot)) translateY(var(--off))` で組み立てている。
**Web Animations API のキーフレームでは `var()` が解決されない**ので、
transform を触るとアニメーション中だけ傾きが失われる。opacity だけを動かすこと。

### 電光掲示板は「窓 + padding-left:100%」

文字列を右端の外から入れるため、`overflow:hidden` の窓の中で
`padding-left:100%` を付け、自身の幅ぶん左へ動かす。
1本だと余白が通過する間に無音になるので、**半周期ずらした2本**を重ねている。

### モバイルメニューはヘッダーより下（z-index 45）

メニューを上に置くとヘッダーごと覆って閉じるボタンが押せなくなる。
ヘッダーは独自の重ね合わせコンテキストを作るので、中のボタンに z-index を振っても効かない。

### 専用のトリミング画像サイズは作らない

`object-fit: cover` で CSS 側がトリミングする。新しい画像サイズを登録すると
**既存の100点超の再生成が必要**になるため、全画像に既にある
`fune-gallery-thumb`(600w) と `large`(1024w) を使い分ける。

### アセットのバージョンは `filemtime()`

固定値だと SCSS を再ビルドしてもブラウザが古い CSS を使い続ける。

### 「今年の点数」は 0 なら直近の年に切り替える

年明け直後などは今年が 0 点になる。0 を大きく出しても情報にならないので、
作品のある直近の年に切り替え、ラベルを `LATEST YEAR` にする。

### 既知の制約

- **`production_date` が空の作品は一覧に出ない。** クエリがこの項目で並べ替え・絞り込みを
  するため。作品を追加したのに出てこない場合はまずここを疑うこと
- **`hover: none` 前提の挙動（スマホでタイトル常時表示）は実機未検証。**
  開発時のブラウザは画面幅を狭めても `hover: hover` を報告するため
